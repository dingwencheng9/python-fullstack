# exercises/ - 练习题

**用途**：巩固数据结构知识点。建议先独立完成，再查看 `solutions/`。

从本课目录运行练习：

```bash
uv run python exercises/01_exercise.py
```

## 文件清单

| 文件 | 说明 | 参考答案 |
|------|------|----------|
| `01_exercise.py` | 列表推导式、词频统计和字典计数 | `solution_01.py` |
| `02_exercise.py` | API 响应防御性解析、默认值处理、字典合并 | `solution_02.py` |
| `03_exercise.py` | 列表推导式 vs 生成器表达式、惰性计算和内存优化 | `solution_03.py` |

## 学习路径

1. **01_exercise.py** — 从列表过滤和词频统计开始，练习 list/dict 基础组合。
2. **02_exercise.py** — 处理嵌套字典，重点关注缺失字段时不崩溃。
3. **03_exercise.py** — 用生成器表达式优化不需要中间列表的大数据计算。
