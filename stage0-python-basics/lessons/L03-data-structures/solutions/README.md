# solutions/ - 参考答案

**用途**：练习完成后的参考答案。

> ⚠️ **建议**：先独立完成 `exercises/`，遇到困难再看 `solutions/`。

## 文件清单

| 文件 | 对应练习 | 说明 |
|------|----------|------|
| `solution_01.py` | `01_exercise.py` | 列表推导式与字典计数 |
| `solution_02.py` | `02_exercise.py` | 嵌套字典安全访问与配置合并 |
| `solution_03.py` | `03_exercise.py` | 生成器表达式与内存友好计算 |

## 运行方式

从本课目录运行：

```bash
uv run python solutions/solution_01.py
uv run python solutions/solution_02.py
uv run python solutions/solution_03.py
```
