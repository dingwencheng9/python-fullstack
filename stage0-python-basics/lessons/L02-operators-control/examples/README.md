# examples/ - 示例代码

**用途**：展示 L02 每个知识点的具体用法。每个文件都可以独立运行。

从本课目录运行：

```bash
uv run python examples/01_arithmetic.py
```

或进入 examples 目录运行：

```bash
cd stage0-python-basics/lessons/L02-operators-control/examples
python 01_arithmetic.py
```

## 文件清单

| 文件 | 说明 |
|------|------|
| `01_arithmetic.py` | 算术运算符 |
| `02_comparison.py` | 比较运算符 |
| `03_logical.py` | 逻辑运算符与短路求值 |
| `04_assignment.py` | 赋值运算符、增强赋值、海象运算符 |
| `05_if_statement.py` | if/elif/else 条件语句 |
| `06_while_loop.py` | while 循环和控制语句 |
| `07_for_loop.py` | for 循环与 range |
| `08_break_continue.py` | break 和 continue |
| `09_for_else.py` | for-else 和 while-else 循环子句 |
| `10_match_case.py` | match-case 模式匹配（Python 3.10+） |
| `11_enumerate_zip.py` | enumerate() 和 zip() 进阶遍历（第 2.9 节） |
