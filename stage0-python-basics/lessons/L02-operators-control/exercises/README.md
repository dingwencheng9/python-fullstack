# exercises/ - 练习题

**用途**：巩固运算符与控制流知识点。建议先独立完成，再查看 `solutions/`。

从本课目录运行练习：

```bash
uv run python exercises/01_arithmetic_conditions.py
```

## 文件清单

| 文件 | 说明 | 参考答案 |
|------|------|----------|
| `01_arithmetic_conditions.py` | 算术运算符与条件语句（BMI、成绩等级） | `solution_01_arithmetic_conditions.py` |
| `02_logical_operators.py` | 逻辑运算符与短路求值（安全访问、状态判断） | `solution_02_logical_operators.py` |
| `03_bitwise_operations.py` | 位运算符应用（奇偶判断、权限管理） | `solution_03_bitwise_operations.py` |
| `04_loops.py` | 循环与循环控制（break/continue/else） | `solution_04_loops.py` |
| `05_match_case.py` | match-case 模式匹配（HTTP 状态码、命令解析） | `solution_05_match_case.py` |
| `06_comprehensive.py` | 综合练习（FizzBuzz、素数判断、计算器） | `solution_06_comprehensive.py` |

## 学习路径

1. **01_arithmetic_conditions.py** — 从算术运算符开始，学习 if/elif/else 多分支
2. **02_logical_operators.py** — 深入逻辑运算符，理解短路求值特性
3. **03_bitwise_operations.py** — 掌握位运算，理解权限标志位设计
4. **04_loops.py** — 学习 for/while 循环，使用 break/continue 控制流程
5. **05_match_case.py** — 掌握 Python 3.10+ 的模式匹配语法
6. **06_comprehensive.py** — 综合练习，串联所有知识点
