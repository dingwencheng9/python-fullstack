## 💡 核心知识点摘要

### 第一章: 传统中间件的设计缺陷

全局中间件难以组合、测试困难、错误处理复杂。
传统中间件模式要求所有路由共享规则，多个中间件顺序敏感导致维护困难。
依赖注入提供路由级别定制、可组合、易测试的现代化方案。

### 第二章: 依赖注入安全网关

FastAPI Dependencies 实现 JWT 验证、用户加载、权限检查的可组合安全链。
Depends() 构建类型安全的认证流程，每个依赖专注单一职责。
课程展示如何组合多个依赖构建复杂的安全策略，同时保持代码清晰可测试。

### 第三章: RBAC 与权限提升防御

基于角色的访问控制（RBAC）替代硬编码权限检查。
RequireRole 依赖实现声明式权限验证，防止权限提升攻击。
课程强调最小权限原则、角色继承、动态权限检查的完整 RBAC 实现。

### 第四章: Rate Limiting 防暴力破解

令牌桶算法、滑动窗口限流保护登录端点。
Redis 实现分布式限流，防御暴力破解和 DDoS 攻击。
课程展示如何根据用户身份、IP 地址、端点类型设置差异化限流策略。

### 最佳实践总结

本课最后的总结章节把教程内容收敛成可执行清单。学习时不要只复制示例代码，要把清单转化为自己的检查流程：输入是什么、输出是什么、失败时如何定位。
