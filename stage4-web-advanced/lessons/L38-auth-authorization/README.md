# L38: 认证与授权

> Stage 4 - Web 进阶 | L38-auth-authorization

## 📚 课程简介

本课程深入讲解认证与授权的核心概念和实践技巧，包括 JWT 认证和 RBAC 权限控制。

## 🚀 快速开始

```bash
# 查看课程内容
cat lesson.md

# 运行示例代码
python examples/01_jwt_auth.py
python examples/02_rbac.py

# 完成练习
cd exercises
python 01_jwt_auth.py
```
