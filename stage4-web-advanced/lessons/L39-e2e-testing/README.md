# L39: E2E 测试工程化

> Stage 4 - Web 进阶 | L39-e2e-testing

## 📚 课程简介

本课程深入讲解 E2E 测试工程化的核心概念和实践技巧，使用 Playwright 进行端到端测试。

## 🚀 快速开始

```bash
# 查看课程内容
cat lesson.md

# 运行示例代码
python examples/01_playwright_basics.py
python examples/02_test_fixtures.py

# 完成练习
cd exercises
python 01_playwright_basics.py
```
