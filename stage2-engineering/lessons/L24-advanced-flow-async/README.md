# L24: 高阶流控与异步协同

> **课程编号**: L24
> **所属阶段**: Stage 2 - 现代化基础内功
> **预计时长**: 6 小时
> **难度**: ⭐⭐⭐⭐ (中高级)
> **前置课程**: L21（异步编程基础）, L23（Python 3.13 新体验）

> ⚠️ **跃升预警**: 本课程是 Stage 2 中最具挑战性的课程之一，是从"基础异步"到"生产级工程"的关键跃升点。

## 🎯 学习目标

完成本课程后，你将能够：

1. ✅ 掌握异步生成器与流式数据处理
2. ✅ 理解 Generator/AsyncGenerator 完整类型语义
3. ✅ 使用 TaskGroup + Semaphore 实现结构化并发控制
4. ✅ 应用 except\* ExceptionGroup 精细化异常处理
5. ✅ 构建类型安全的流式 ETL 和生产级异步管道

## 快速开始

### 1. 安装依赖

本课程核心内容**不需要额外依赖**，使用 Python 3.13 标准库即可。

部分练习需要 `aiofiles`（异步文件 I/O）：

```bash
uv pip install aiofiles
```

### 2. 运行测试

```bash
uv run pytest tests/ -v
# 44 passed
```
