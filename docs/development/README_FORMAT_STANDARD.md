## 一、设计原则

### 1.1 README vs lesson.md 区别

| 维度 | README.md | lesson.md |
|------|-----------|-----------|
| **受众** | 快速浏览者（30 秒决策） | 深入学习者（2 小时阅读） |
| **目的** | 概览 + 快速启动 | 详细教学 |
| **内容** | 精简结构化信息 | 完整教学内容 |
| **行数** | 50-150 行 | 500-2000 行 |

### 1.2 设计原则

1. **30 秒原则**：读者 30 秒内能理解课程价值
2. **可操作性**：每个步骤都可执行
3. **结构化**：层级清晰，扫描友好
4. **自包含**：无需阅读 lesson.md 也能开始

---

## 二、README 级别标准

### 2.1 三级标准

| 级别 | 适用场景 | 章节数 | 行数 |
|------|---------|--------|------|
| **Core** ⭐ | 占位/大纲 | 4 个 | 30-60 |
| **Standard** ⭐⭐ | 进阶课程 | 8 个 | 60-150 |
| **Extended** ⭐⭐⭐ | 核心/入门课程 | 10 个 | 100-200 |

### 2.2 级别判定

```
是 Stage 0 课程？
├─ 是 → Extended（强制）

课程内容 ≥ 100 行且有完整元数据？
├─ 是 → Standard 或 Extended

仅占位/大纲？
└─ → Core
```

## 六、README vs lesson.md 内容分工

### 6.1 内容分配

| 内容 | README | lesson.md |
|------|--------|-----------|
| 学习目标 | ✅ 精简版（4-5 条） | ✅ 详细版（5-8 条） |
| 核心内容 | ✅ 概览表格 | ✅ 详细讲解 |
| 快速开始 | ✅ 完整可执行 | ❌ 不重复 |
| 常见陷阱 | ✅ 精简版（1-2 个） | ✅ 完整版（3-5 个） |
| 实用技巧 | ✅ 精简版（2-3 个） | ✅ 完整版（4 个） |
| 练习题 | ✅ 题目列表 | ✅ 详细分析 |
| 参考资料 | ✅ 链接 | ✅ 详细说明 |
| 文件导航 | ✅ 完整 | ❌ 不重复 |

### 6.2 黄金比例

```
README:lesson.md = 1:5 到 1:10

示例：
- README: 100 行
- lesson.md: 500-1000 行
```
