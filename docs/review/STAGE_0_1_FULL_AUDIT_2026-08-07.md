## 二、Stage 0 vs Stage 1 设计差异分析

### 2.1 章节结构设计模式

**Stage 0 (入门课程)** 采用「宽松结构」:
```
## 📚 延伸阅读
## ✅ 自检清单
## 💭 课堂思考
## 📝 进阶预告
## 🔗 下一步
```

**Stage 1 (进阶课程)** 采用「紧凑结构」:
```
## 📝 本章总结
## 💭 课堂思考
## 📚 参考资料
## 📁 文件导航
## ✅ 完成标准
## 💡 常见陷阱
## 🔗 下一步
```

### 2.2 元数据格式差异

| 字段 | Stage 0 | Stage 1 |
|------|---------|---------|
| 版本 | ✅ 有 | ❌ 无 |
| 最后更新 | ✅ 有 | ❌ 无 |
| 难度 | ✅ 有 | ✅ 有 |
| 预计时长 | ✅ 有 | ✅ 有 |
| 前置课程 | ✅ 有 | ✅ 有 |

### 2.3 评估结论

**设计差异不是问题**，而是教学阶段的合理选择：
- Stage 0 面向零基础学员，需要「自检清单」帮助确认学习效果
- Stage 1 面向进阶学员，侧重「完成标准」和「常见陷阱」

**真正需要统一的是**:
1. Stage 1 缺少 `版本` 和 `最后更新` 元数据
2. Stage 1 缺少「自检清单」或等效的「完成标准」章节
