## 🎯 阶段目标

掌握 Python 爬虫的完整技术栈，从基础的网页解析到高级的 JavaScript 逆向和 App 逆向，能够独立完成各类网站的爬取任务。

### 能力等级

| 等级 | 描述 |
|------|------|
| P1 | 基础网页爬取（静态页面） |
| P2 | 动态页面与自动化抓包 |
| P3 | JavaScript 逆向分析 |
| P4 | App 逆向与移动端抓取 |
| P5 | 综合实战与反反爬策略 |
