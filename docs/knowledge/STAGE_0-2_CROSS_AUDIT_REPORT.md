## 五、后续建议

### 5.1 定期同步机制

建议在以下时机同步 `KNOWLEDGE_INVENTORY.md` 与 `lesson.md`:
- 新增课程时
- 修改课程前置依赖时
- 课程重组时

### 5.2 自动化检查

可添加 CI 检查脚本，验证:
```python
# 伪代码
for lesson in all_lessons:
    expected = get_prerequisites_from_lesson_md(lesson)
    documented = get_prerequisites_from_knowledge_inventory(lesson)
    assert expected == documented, f"Mismatch for {lesson}"
```
