## 💡 核心知识点摘要

### 第一章: Matplotlib 基础

Matplotlib 是 Python 可视化底层工具。
课程覆盖折线、柱状、散点、直方、饼图和箱线图，并说明每种图的适用场景，如趋势、对比、关系、分布和异常值。

### 第二章: Seaborn 统计可视化

Seaborn 封装了常用统计图。
热力图适合相关性矩阵，小提琴图展示分布形态，pairplot 观察变量组合关系，jointplot 适合双变量分布。

### 第三章: 图表定制化

专业图表需要布局、样式、颜色和标注。
课程介绍子图网格、主题设置、调色板和文本注释，目标是让图表既美观又不牺牲准确性。

### 第四章: 可视化最佳实践

选图原则比 API 更重要。
课程按变量类型和分析目的选择图表，强调使用语义配色、避免 3D 饼图、避免截断轴误导读者，并用流程化方式完成仪表板。

### 最佳实践总结

本课最后的总结章节把教程内容收敛成可执行清单。学习时不要只复制示例代码，要把清单转化为自己的检查流程：输入是什么、输出是什么、失败时如何定位。
