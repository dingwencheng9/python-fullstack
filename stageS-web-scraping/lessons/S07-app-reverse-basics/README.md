# S07: App 逆向入门

> **课程编号**: S07

> **难度**: ⭐⭐⭐⭐☆

## 🎯 学习目标

完成本课程后，你将能够：

1. **理解 Android 架构**：APK/DEX/SDK/NDK
2. **使用反编译工具**：apktool、Jadx、模拟器
3. **进行网络抓包**：Charles、HttpCanary
4. **调用 Java 方法**：jpype、PyJnius

## 知识点

| 层级 | 知识点 | 说明 |
|------|--------|------|
| L1 | Android 架构 | APK/DEX/SDK/NDK |
| L1 | Java 核心语法 | 类/对象/接口/泛型 |
| L2 | APK 分析 | apktool/Jadx/模拟器 |
| L2 | 反编译技术 | DEX 反编译、资源反混淆 |
| L2 | 网络抓包 | Charles/HttpCanary |
| L3 | native 函数 | SO 库、ABI、寄存器 |
| L3 | 签名与校验 | 签名验证、反调试 |
| L3 | Python 调用 Java | jpype、PyJnius |
