# S01: 前端基础 — HTML/CSS/DOM

> **课程编号**: S01
> **所属阶段**: Stage P - Python 爬虫专精
> **课程时长**: 6 小时
> **难度**: ⭐☆☆☆☆ (入门)
> **前置课程**: L01 Python 核心语法
> **核心版本**: Python 3.13+

---

## 🎯 学习目标

完成本课程后，你将能够：

1. **理解 HTML 结构**：掌握标签、元素、属性的基本概念
2. **使用 CSS 选择器**：熟练使用 id/class/标签选择器定位元素
3. **使用开发者工具**：掌握 Chrome DevTools Elements 和 Network 面板
4. **理解 DOM 树结构**：了解父子兄弟节点关系
