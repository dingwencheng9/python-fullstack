## 🎯 学习目标

完成本课程后，你将能够：

1. **理解 Scrapy 架构**：Engine、Spider、Pipeline、Scheduler
2. **开发 Scrapy Spider**：编写高效的爬虫代码
3. **使用 Item Pipeline**：数据清洗与存储
4. **掌握分布式爬虫**：Scrapy-Redis
