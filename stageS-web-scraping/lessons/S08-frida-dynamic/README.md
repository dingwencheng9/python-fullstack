# S08: Frida 动态分析

> **所属阶段**: Stage P - Python 爬虫专精

> **难度**: ⭐⭐⭐⭐⭐
> **前置课程**: S07
> **核心版本**: Python 3.13+

## 🎯 学习目标

完成本课程后，你将能够：

1. **使用 Frida 框架**：frida-server、模拟器配置
2. **编写 Hook 脚本**：JavaScript API、主动调用
3. **进行 RPC 远程调用**：网络接口、本地服务
4. **进行 SO 逆向**：符号查找、Inline Hook
