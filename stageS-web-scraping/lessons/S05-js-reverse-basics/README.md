# S05: JavaScript 逆向基础

> **课程编号**: S05
> **所属阶段**: Stage P - Python 爬虫专精
> **课程时长**: 10 小时
> **难度**: ⭐⭐⭐⭐☆
> **前置课程**: S01, L16
> **核心版本**: Python 3.13+

---

## 🎯 学习目标

完成本课程后，你将能够：

1. **理解 JS 核心语法**：ES6+、Promise、async/await
2. **使用浏览器调试**：Source 面板、断点、调用栈
3. **理解加密算法基础**：MD5/SHA/AES/RSA
4. **掌握代码扣取技巧**：本地运行、模拟执行
