# S02: 网页数据解析 — XPath 与 Beautiful Soup

> **课程编号**: S02
> **所属阶段**: Stage P - Python 爬虫专精
> **课程时长**: 8 小时
> **难度**: ⭐⭐☆☆☆
> **前置课程**: S01, L16 (正则表达式)
> **核心版本**: Python 3.13+

---

## 🎯 学习目标

完成本课程后，你将能够：

1. **使用 Requests 库**：发送 HTTP 请求，处理响应
2. **掌握 XPath 语法**：编写高效的数据提取表达式
3. **使用 Beautiful Soup**：解析 HTML 文档，提取数据
4. **应对反爬策略**：UA 伪装、延时、代理池
