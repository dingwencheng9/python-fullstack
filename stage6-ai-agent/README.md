# Stage 6: AI Agent 开发 — 从工具调用到自主决策

> **课程数量**: 12 节（L54-L65）
> **难度**: ⭐⭐⭐⭐⭐
> **预计时长**: 50-60 小时
> **目标产物**: 能独立部署的多 Agent 系统 + 评估/监控/MCP 工具协议
> **分类**: CORE（所有 AI 应用的基础能力）

---

## 🎯 Stage 6 在整个课程中的定位

```
Stage 0-5 (全栈工程 + 数据能力)
                  ↓
┌─────────────────────────────────────┐
│         Stage 6 (AI Agent)          │
│         — CORE — 所有学生必修        │
│         L54-L65                     │
└─────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────┐
│      Stage A (AI Agent 企业级)       │
│      — SPECIALIZATION — 按方向选修   │
│      A01-A20                        │
└─────────────────────────────────────┘
                  ↓
              Stage P/K/M/R (其他专项)
```

**Stage 6 是 CORE 阶段的最后模块**，综合了前面所有技能：
- 综合 Stage 3 的 FastAPI/SSE
- 综合 Stage 4 的异步与背压
- 综合 Stage 5 的 RAG 向量召回
- 加上 Agent 的规划、记忆、工具调用、多智能体协作
- 形成**真正可商用的 AI 应用**
