# L51 Solutions 说明

本目录提供两套参考实现：

| 文件                          | 教学定位                                                       | 推荐场景                            |
| ----------------------------- | -------------------------------------------------------------- | ----------------------------------- |
| `01_embedding_pipeline.py`    | 同步版本，演示文本预处理、缓存、批处理嵌入的核心流程           | 与 lesson.md 主线一致；课堂演示首选 |
| `sol01_embedding_pipeline.py` | 异步版本，加入 OpenTelemetry 观测、tenacity 重试、严格异常处理 | 生产风格，扩展阅读                  |
| `02_vector_search.py`         | 同步版本，演示向量检索和 Qdrant API 调用                       | 与 lesson.md 主线一致               |
| `sol02_vector_search.py`      | 异步版本，演示并发检索、批量查询                               | 生产风格，扩展阅读                  |

> 主练习路径以 `01_*.py` / `02_*.py` 为准；`sol*.py` 是补充材料。
