## 💡 核心知识点摘要

### 第一章: 评估指标体系

评估不能只看主观感觉。
课程建立任务成功率、平均延迟、Token 使用、错误率、LLM-as-Judge 评分和成本效益指标，用数据判断 Agent 是否可上线。

### 第二章: 调试技术

Agent 调试需要看完整轨迹。
LangSmith、Callbacks 和日志追踪能记录 prompt、工具调用、中间步骤、异常和模型输出，帮助定位失败发生在哪一环。

### 第三章: 性能优化

性能优化从 Profiling 开始。
课程关注瓶颈识别、Prompt 精简、Token 优化、并行执行和缓存，把质量、延迟与成本一起纳入优化目标。

### 第四章: 自动化测试

Agent 测试要分层。
单元测试工具和解析器，集成测试完整链路，端到端测试真实任务。
测试集应包含成功、失败、边界和恢复场景。

### 最佳实践总结

本课最后的总结章节把教程内容收敛成可执行清单。学习时不要只复制示例代码，要把清单转化为自己的检查流程：输入是什么、输出是什么、失败时如何定位。

### 练习题定位

练习题用于把概念转成工程能力。建议先独立完成 `exercises/`，再对照 `solutions/` 检查边界处理、类型注解、错误信息和测试覆盖。
