本课程讲解如何为 Agent 构建持久化和智能的记忆系统。

## 📌 学习目标

1. 理解 Agent 记忆的类型
2. 掌握短期记忆与长期记忆的实现
3. 构建智能的记忆检索系统
4. 实现记忆的遗忘机制

## 📚 课程内容

### 第一部分：记忆类型

- 感官记忆（感官输入）
- 短期记忆（工作记忆）
- 长期记忆（持久化）

### 第二部分：记忆实现

- 基于向量数据库的记忆存储
- 记忆的压缩与摘要
- 上下文窗口管理

### 第三部分：智能检索

- 基于相关性的检索
- 时间衰减权重
- 重要性评分
