本课程讲解如何让 Agent 具备规划、推理和解决问题的能力。

## 📌 学习目标

1. 理解 Agent 规划的重要性
2. 掌握常见的规划算法
3. 实现 ReAct、CoT 等推理模式
4. 构建自我改进的 Agent

## 📚 课程内容

### 第一部分：规划基础

- 任务分解（Task Decomposition）
- 子目标生成
- 执行计划

### 第二部分：推理模式

- Chain-of-Thought (CoT)
- ReAct（推理 + 行动）
- Tree of Thoughts (ToT)

### 第三部分：自我改进

- 反思与总结
- 错误纠正
- 学习与适应
