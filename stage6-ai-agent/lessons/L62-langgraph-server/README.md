本课程深入讲解 LangGraph，一个基于 LangChain 构建复杂 Agent 工作流的框架。

## 📌 学习目标

1. 理解状态机和工作流的概念
2. 掌握 LangGraph 的核心组件
3. 构建多步骤的复杂 Agent 工作流
4. 实现条件分支和循环

## 📚 课程内容

### 第一部分：LangGraph 基础

- 状态机与 DAG 的关系
- 节点（Node）和边（Edge）的定义
- 状态（State）的定义和管理

### 第二部分：复杂工作流

- 条件分支与路由
- 循环与迭代
- 并行与串行执行

### 第三部分：生产实践

- 错误处理与重试
- 人机协作
- 记忆与上下文管理

## 🚀 快速开始

```bash
uv add langgraph langchain-core
```
