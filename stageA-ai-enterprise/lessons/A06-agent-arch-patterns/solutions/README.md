# A06 参考答案

本目录包含 A06 课程的参考实现代码，供学生对照学习和检查作业完成进度。

## 文件说明
- `solution_*.py` - 每个练习题的完整实现
- `verify.py` - 自动化验证脚本

## 使用指南
```bash
# 对比自己的实现与参考答案
python solution_agent_arch.py

# 或运行验证脚本
python verify.py
```

## 注意事项
- 请先独立完成练习，再对照参考答案
- 鼓励尝试其他优秀的实现方式
- 参考答案仅供参考，允许不同的合理实现方式
