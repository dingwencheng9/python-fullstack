# 主动询价话术模板

> 守株待兔接单效率低。**主动出击 = 单量翻 10 倍**。
> 但乱发广告 = 被拉黑 + 丢人。下面是不丢人的主动询价方式。

---

## 三种主动询价场景

### 场景 1：朋友圈 / 社群有人发"找人做 X"

**❌ 错误回复**：

> "我可以做"
> "我会 Python"
> "+1 我也来"

**✅ 标准回复**：

> "您好，看到您要做 [具体需求]。
> 我做过类似的：[1 句话案例 + 链接]。
> 这个需求我大概能在 [X 天] 内交付，预算大概 [Y 元]，您方便加我微信详聊吗？"

**关键点**：

1. 提到具体需求（让对方知道你认真看了）
2. 给具体案例（建立信任）
3. 给具体工期/预算（让对方觉得你靠谱）
4. 引导到私聊（不要在公开场合谈细节）

---

### 场景 2：在 Upwork / Fiverr / 猪八戒投标

**❌ 错误模板**：

> "Hello, I'm a Python developer with 5 years of experience..."
> （这样的开头客户每天看 50 条，秒滑走）

**✅ 黄金 30 秒模板**：

```
Hi [客户名]，

注意到您要做 [客户需求的 1 个关键词，证明你看了]。

类似的我做过这个：[1 个最相关的案例链接 + 1 句话效果]
比如，我帮 [类似客户类型] 做了 [类似功能]，[量化结果]。

针对您的需求，我看到关键挑战是 [指出 1 个客户没说但你专业判断的难点]。
我的方案是 [1-2 句话方案]，工期约 [X 天]，预算 [区间]。

我可以先做一个 [免费的 30 分钟需求确认 / 5 分钟小 demo]，
您看可以吗？

[你的名字]
[相关作品集链接 1 个]
```

**关键点**：

1. **第一句不是自我介绍**，是证明你看了客户需求
2. 案例必须**直接相关**（爬电商数据 vs 爬政府网站差别很大）
3. **指出客户没看到的问题** = 显示专业（这是和其他投标人的最大区别）
4. **降低试用门槛**（免费 30 分钟通话 / 5 分钟小 demo）
5. 短！不超过 200 字！

### 场景 3：冷启动主动找潜在客户

#### 找谁？

| 客户类型         | 怎么找                 | 报价方向           |
| ---------------- | ---------------------- | ------------------ |
| 小程序开发工作室 | 即刻、V2EX、本地创业群 | API 后端外包       |
| 小型电商         | 1688、淘宝小卖家社群   | 数据采集 + 报告    |
| 公众号/自媒体    | 内容创作者社群         | 内容数据分析       |
| 律所/会计所      | LinkedIn / 行业群      | RAG 知识库         |
| 培训机构         | 知识付费圈子           | AI 客服 + 课程问答 |

#### 怎么开口？

**❌ 错误开头**：

> "您好，我是 Python 开发，需要外包请联系"
> （像群发广告，秒被删除）

**✅ 标准模板（针对小型电商）**：

```
李总你好，

看到您在 [群名/朋友圈] 提到最近在做 [具体业务]。
我注意到 [一个具体观察，比如：您的产品在 X 平台的曝光数据这周下滑了]。

我专门做电商数据分析，用 Python 做过几个类似的项目：
- 帮 [客户类型] 做了 [价格监控系统]，每天自动监控 200 个 SKU
- 给 [客户类型] 做了 [周报系统]，老板每周一早上自动收到分析报告

如果您有兴趣，我可以送您一份 [您的店铺 X 平台的免费分析样例]，
看完无任何责任，要不要做都可以。

[你的名字]
[GitHub / 个人主页]
```

**关键点**：

1. **先观察、后开口**：花 5 分钟研究对方，不要群发
2. **送价值优先**：免费给一份小报告，不是直接推销
3. **降低决策成本**："看完无任何责任"
4. **永远附上你的个人页面**：建立信任

## Cold Email / DM 实战话术

### 模板 A：找 SaaS 创业团队（接 API 后端）

```
Subject: [产品名] 后端，可能能帮上忙

[姓名]，

我用了一周您的 [产品名]，注意到 [具体观察，比如 API 响应慢、缺少 Webhook、文档不全]。

刚好我做 Python 后端比较多，最近用 FastAPI 给 [类似团队] 做了：
- [具体功能 1]
- [具体功能 2]

不知道您团队后端有没有外包需求？
如果方便，可以发您一份我的 1 分钟 demo 视频。

[你的名字]
[个人页]
```

### 模板 B：找内容创作者（接数据分析）

```
[创作者] 您好，

是您 [某篇文章 / 视频] 的读者，想咨询一个合作。

我专门做 Python 数据分析，注意到您可能需要：
- 公众号 / 视频号的数据周报
- 内容选题趋势分析
- 粉丝评论情绪分析

我可以**先免费给您做一份样例**（您的某个账号过去 30 天数据分析），
看完合适再聊后续合作。

无任何责任，您看可以加微信发您吗？

[你的名字]
[作品集]
```

### 模板 C：找律所 / 教育机构（接 RAG）

```
[抬头] 您好，

最近我在做 AI 知识库系统，专门针对 [律所 / 教培机构] 这类**文档密集型** 行业。

具体能解决：
- 员工查内部资料从 30 分钟 → 30 秒
- 标准化重复问题，减少培训成本
- 完全私有化部署，文档不出公司

如果您想了解，我可以发一段 5 分钟视频演示，
您方便的话我们可以视频通话 30 分钟，**纯交流不推销**。

[你的名字]
[公司案例（如有）]
```

## 数据：转化率参考

| 渠道        | 单条触达成本 | 回复率          | 成单率          | ROI                  |
| ----------- | ------------ | --------------- | --------------- | -------------------- |
| Cold Email  | 几乎 0       | 1-3%            | 10-20% 回复转化 | 中                   |
| LinkedIn DM | 0            | 5-10%           | 20-30% 回复转化 | 高                   |
| 微信群发    | 0            | 0.5% 以下       | < 5%            | 极低（且容易被拉黑） |
| Upwork 投标 | 1 个 connect | 10-20% 收到回复 | 5-10% 中标      | 中                   |
| 朋友圈被动  | 0            | 看你已发布      | 看精度          | 高                   |

> 💡 **结论**：DM/邮件 > 投标 > 群发。**永远不要在大群里发广告。**

## 进阶：被动获客的种子

主动询价是开始，但**长期生意靠被动获客**。

### 持续做 3 件事，6 个月后自然有客户找你：

#### 1. 写技术博客 / 小红书 / 即刻

- 每周 1-2 篇短文
- 选题：**项目踩坑** + **技术对比** + **客户案例**
- 不写鸡汤、不写大而全的入门教程

#### 2. 开源 + Star 累积

- 把你做客户项目的**通用部分**抽出来开源
- 比如：合规爬虫框架、FastAPI 项目模板、RAG 起手包
- 1 个 100+ star 的开源项目 = 100 个被动询价

#### 3. 在垂直社区贡献

- V2EX、即刻、Reddit r/Python、HackerNews 评论区
- 不要硬广，**回答专业问题**
- 时间一长，提到该领域大家就想到你

## 检查清单

发出主动询价前，对照这 5 条：

- [ ] 我看过对方的需求 / 业务，**不是群发**
- [ ] 我有相关案例可以贴（不是吹牛）
- [ ] 我给了具体的工期/预算区间
- [ ] 我降低了对方的决策成本（免费 demo / 试用）
- [ ] 我的开头不是"您好我是 XX"

---

## 心态调整

1. **被拒绝是常态**：90% 的主动询价不会有回应。**这不是你的问题，是数学问题**。
2. **不要追单**：发一次没回，等 3-7 天 follow-up 一次。再没回就放弃。
3. **质量 > 数量**：1 天精心写 5 条 vs 1 天群发 100 条——前者效果是后者 10 倍。
4. **建立信任比成单重要**：第一次没合作没关系，半年后对方需要时会想起你。
5. **不要为单价不高的客户低三下四**：你提供的是真实价值，**对方应该是来求购的，不是来恩赐的**。
